# Vocabulary

Words as this project uses them.

- **Growth Portal**: this app. Dashboards for the growth team about KTHAIS's Luma community.
- **Luma**: the event and community platform KTHAIS runs its calendar on.
- **luma-service**: the KTHAIS service that talks to Luma. This app's only source of Luma data.
- **Community tier**: the Luma membership tier the growth team analyses. Configured in luma-service.
- **Member**: a person with an approved membership in the Community tier.
- **Registration question**: a question asked when joining the tier, e.g. graduation year or areas of
  interest.
- **Answer**: a member's answer to a question; a list of values (several for multi-select).
- **Demographics**: the counts of answers per question across all members, e.g. 40 members graduating
  in 2027. The only thing the API returns about members.
- **Dashboard**: a page of the frontend showing demographics.
